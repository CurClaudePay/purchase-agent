# Mock data

Shared, fictional data used by every team. Everything here is invented: no real
people, IBANs, phone numbers or accounts. Add new data here rather than in team folders.

| File                  | Contents                                   |
|-----------------------|--------------------------------------------|
| `coffee-machine.json` | The consumer's coffee machine and its bean level |
| `products.json`       | The merchant's catalogue                   |
| `accounts.json`       | Consumer, agent and merchant accounts with sandbox balances |
