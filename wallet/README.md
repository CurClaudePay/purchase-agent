# Wallet

Owned by the **Wallet** team. Read the root `CLAUDE.md` first.

- **Funds**: balances for the fictional accounts in `mock-data/accounts.json`.
- **Limits**: wallet-side spending limits, checked in addition to the mandate.
- **Settlement**: moves funds from consumer to merchant on the sandbox, only
  against an approved authorisation from the Trust Layer.

Sandbox only. Nothing here connects to a real Wero or bank endpoint.
