# Trust Layer

Owned by the **Trust Layer** team. Read the root `CLAUDE.md` first. This team
also owns `contracts/`.

- **Mandate validation**: registers mandates and agent identities, and decides
  each authorisation request against the mandate (see `contracts/authorisation.schema.json`
  for the refusal reasons).
- **Audit trail**: an append-only log of every mandate, identity, authorisation,
  payment and order event, readable at the end of the demo.
