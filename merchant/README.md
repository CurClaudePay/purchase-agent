# Merchant

Owned by the **Merchant** team. Read the root `CLAUDE.md` first.

Serves the fictional coffee shop the agent buys from:

- **Catalogue**: products from `mock-data/products.json`.
- **Offer**: a priced, time-limited offer for a product and quantity.
- **Order**: created once the wallet confirms settlement.
- **Delivery**: a simulated delivery status for the order.
